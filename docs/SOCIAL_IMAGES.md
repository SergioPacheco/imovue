# Imagens para redes sociais

Os arquivos sociais ficam em `frontend/public/` e são publicados diretamente pelo domínio do Imovue.

| Arquivo | Dimensão | Uso recomendado |
| --- | ---: | --- |
| `og-social.png` | 1731 × 909 | Facebook, WhatsApp, Telegram, LinkedIn e prévia Open Graph |
| `social-landscape.png` | 1672 × 941 | Publicação horizontal alternativa e materiais para X |
| `social-instagram-feed.png` | 1122 × 1402 | Instagram Feed vertical (proporção 4:5) |
| `social-instagram-story.png` | 941 × 1672 | Instagram Stories e Reels (proporção 9:16) |
| `social-square.png` | 1254 × 1254 | Instagram/Facebook em formato quadrado |

O site usa `https://imovue.com.br/og-social.png` como imagem Open Graph. Assim, links compartilhados no Facebook, WhatsApp, Telegram e LinkedIn recebem o banner horizontal. O X também recebe essa imagem pelo campo `twitter:image`, por ser a opção mais próxima do formato horizontal recomendado para cards grandes.

O Instagram não permite escolher a imagem de uma publicação por meio do link de compartilhamento do site. Para publicação manual, use a versão correspondente ao formato desejado.
